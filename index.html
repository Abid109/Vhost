ℹ️ How to set up Backblaze B2

1. Go to backblaze.com → sign up free
2. B2 Cloud Storage → Buckets → Create Bucket (set to Private)
3. App Keys → Add New Application Key
4. Set access to Read & Write for your bucket
5. Copy the keyID and applicationKey
6. Find your endpoint in Bucket Settings
⚠️ Important: Your keys are stored only on this device. Never share them with anyone. Delete and recreate keys if compromised.
